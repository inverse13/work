Track Harder. Share Smarter. Dominate Together.

The ultimate self-hosted fitness social platform — better than Whoop in every way.

## Quick Start

1. Clone: `git clone https://github.com/inverse13/work.git`
2. `npm install`
3. Copy `.env.example` to `.env.local` and fill vars
4. `npx prisma generate && npx prisma db push`
5. `npm run dev`

## Features
- Black/red/white cyber theme
- Auth, paid communities, posts
- Stripe + Crypto payments
- Wearable imports
